# Stress test 1 — the blind-coding pilot

**Status.** Companion to `link-sketch-blocks-AB.md`. Tests whether separability and documentation density can be coded **ex ante** — the gate for folding the task anatomy into Block B.0′.

**Honesty preamble.** I know how these cases turned out. What this pilot can deliver is *procedural* blindness — the rule written first, applied uniformly, no per-case amendments — not *epistemic* blindness. Three things restore teeth: the rule is now fixed in print and a third party (you, or an RA) can re-apply it to fresh cases without seeing my table; the pending set at the end is pre-registered before outcomes exist; and every deviation the scoring needed is reported as a deviation, not absorbed silently. One deviation occurred and is flagged (pharmacist).

## 1. The rule (written before scoring)

### Dimensions (pilot list; the paper imports O*NET's)

| Code | Dimension |
|---|---|
| FRC | Gross force / power |
| PRS | Fine motor in **structured** environments (fixtured, repeatable) |
| UNS | Manipulation & mobility in **unstructured** environments (variable sites, floppy materials, clutter) |
| PER | Perception / recognition (visual, auditory patterns) |
| SYM-R | Symbolic, rule-following (lookup, arithmetic, codified procedure) |
| SYM-O | Symbolic, open (language, synthesis, novel composition) |
| SOC | Social interaction (real-time rapport; sub-code co-present vs remote) |

### Ray table (crossing ≈ machines reach working-professional level in engineered conditions)

| Ray | Crossed | Vehicle | Type |
|---|---|---|---|
| FRC | ~1850–1930 | steam, IC, hydraulics | engineering |
| SYM-R | ~1890–1980 | tabulators, relays, computers | engineering |
| PRS | ~1910–1990 | machine tools, fixed automation, caged robots | engineering |
| PER | 2012– | deep learning | **learning** |
| SYM-O | 2020– | LLMs | **learning** |
| SOC (remote) | 2022– (partial) | LLMs | **learning** |
| UNS | not crossed | robotics pending; corpus being manufactured via teleoperation | **learning** |
| SOC (co-present) | not crossed | — | **learning** |

**Refinement logged during rule-writing, before any scoring:** D gates only the **learning** rays. Engineering rays cross by design — an engine needs no corpus. D is therefore scored only where a task's exposure runs through PER / SYM-O / SOC / UNS.

### Separability (unit = component pair, not whole task)

Two components are **separable** iff either holds, judged on the task as it existed *before* the wave:

- **Buffer test:** the output of one component can be stored or queued before the other acts.
- **Narrow-channel test:** coordination between them fits a low-bandwidth channel (levers, tickets, messages) without degrading the deliverable.

**Bundled** iff they demand one agent, one body, one real-time loop (sub-second cross-dimension feedback, or physical co-location of sensing and acting). Admissible ex-ante evidence: historical division-of-labour precedent; existence of a remote or split variant; environment engineering (assembly line, container) — which counts as **manufactured separability** and is itself predictable investment wherever the wage bill is large.

### Documentation density D (per component, on the eve of the relevant wave)

- **HIGH:** a written procedure suffices for a competent novice, **or** input→output pairs accrue as digital exhaust of normal work.
- **LOW:** competence transmits by demonstration and feel; experts cannot articulate the policy.
- **MED:** partial procedures plus tacit residue.

### Prediction mapping

1. All engaged components crossed (D ≥ MED where learning-gated) → **FLIP**.
2. Proper subset crossed, boundary **separable** → **PARTIAL**: machine takes crossed components; human residue on uncrossed with machine multiplier; headcount falls; wage path *continuous*, sign set by whether decomposition raises or lowers the residual requirement.
3. Proper subset crossed, boundary **bundled** → **UNTOUCHED**; punctuated flip when the last ray crosses.
4. Learning-gated ray with D = LOW → **DELAYED** until a corpus is manufactured.
5. **Wedge overlay** (adoption ≠ capability): admissible only with a citable statute or contract; predicts punctuated adoption per the paper's fortification remark.

## 3. Score

**Bare rule, outcome classification: 20 / 21.** The pharmacist is the genuine miss: capability crossed decades ago, occupation intact — nothing in the task anatomy predicts survival; only the licensure wedge does.

**With the documented-wedge overlay: 21 / 21.** The overlay was invoked five times (8, 11, 12, 20, 21) — twice for timing only, twice for adoption lag, once as full rescue — and in every instance the instrument is independently citable (contract or statute), which is the admissibility bar that keeps it from being an escape hatch. The overfitting worry is stated rather than waved: an overlay that can be invoked is an overlay that can be abused, and the discipline is that it may **only** be invoked with a document in hand.

## 4. What the test forced (findings, not patches)

1. **D gates learning rays only.** Engineering rays cross by design. (Logged during rule-writing.)
2. **Separability is component-wise.** The unit of analysis is the component pair; whole-task coding fails on the server and the teller.
3. **The wedge overlay is load-bearing.** The task anatomy alone under-predicts survival wherever licensure binds (pharmacist, pilot, radiology-adoption). Consequence for the paper: **B.0′ and Block D are co-dependent and must fold in together** — neither anatomy classifies alone.
4. **Scope boundary: the classifier speaks at task level.** Occupation outcomes add demand elasticity and recomposition (teller, typist→assistant). Print the boundary; don't claim the occupation.

## 5. Verdict

**Gate passed.** The rule survived uniform application without per-case contortion; the one bare miss is exactly the case the μ-anatomy exists to catch. Recommendation: fold the task anatomy into B.0′ with amendments 1–4, and draft Block D in the same pass. The genuinely blind test is below, plus third-party recoding: the rule in §1 is self-contained — apply it to fresh cases without reading §2.
