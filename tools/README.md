# tools

Editing utilities shared across the threads.

- `word_diff_report.py` — word-level HTML diff between two prose files (the diff-reading workflow for edits that arrive by paste).
- `reading_view.py` — every changed paragraph as clean prose, for reading a candidate edit in context.
- `render_pdf.py` — HTML to a selectable-text PDF through Chromium (usage in the file header).
