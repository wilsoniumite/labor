# LaTeX project — Pinning the Wage to Scarcity and Technology

Overleaf-ready LaTeX version of `../paper/pinning.html`, generated by
`../code/html_to_latex.py`. **The HTML stays canonical**: edit there (with the
usual check/lint discipline), then regenerate:

    ../venv/Scripts/python.exe code/html_to_latex.py     # from dynamics/

The generator verifies its own output: word-sequence fidelity against the HTML
(13,289 tokens, zero diff hunks), section/proposition/figure/equation numbering,
environment and brace balance, and that every `\ref` resolves to a defined
`\label`. Hand edits made only in `main.tex` will be lost on regeneration —
back-port them to the HTML (as done 2026-08-21 with Wilson's voice pass).

## Cross-references (generated 2026-08-21)

Every numbered object carries a stable `\label`, and every in-prose mention is
emitted as `\ref` — so reordering sections, propositions, figures, or register
items in LaTeX renumbers all mentions automatically. Label names are keyed to
content, not position (`sec:ceiling`, `app:race`, `prop:fork`, `fig:kappa`,
`eq:closure`, `pred:exit`), safe to cite in new co-author text. The full map
lives in `../code/html_to_latex.py` (`HEAD_LABELS` etc.). Two consequences:
retitling a heading in the HTML fails the converter until the map learns the
new title (deliberate), and the HTML itself still spells references literally
("Section 4") — restructuring at the HTML level means updating those mentions
there, which the converter's rewrite-and-sweep then re-verifies.
